Primary call-to-action for ScopeBolt — an ink (near-black) pill by default; reserve the orange `brand` variant for one hero moment per view.

```jsx
<Button variant="primary" size="lg" withArrow>Start free — no card needed</Button>
<Button variant="secondary">Book demo</Button>
<Button variant="brand" withArrow>Start free trial</Button>
<Button variant="ghost" size="sm">Pricing</Button>
```

Variants: `primary` (ink/zinc-900, default), `brand` (orange #e8440a, use sparingly), `secondary` (white + zinc border), `ghost` (text only). Sizes `sm | md | lg`. Set `withArrow` for the rightward CTA arrow, `href` to render an anchor.
